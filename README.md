# STEM-проєкт з КГВ

Обробка та аналіз супутникових знімків класичними методами комп'ютерної графіки.

Програма бере супутникові знімки, проганяє їх через ланцюжки методів обробки (пайплайни) і зберігає результат кожного кроку. Потім за метриками PSNR, MSE і SSIM ми порівнюємо, який пайплайн краще працює і де помиляється.

Нейромережі та машинне навчання не використовуємо. Усі методи обробки написані вручну, бібліотеки потрібні тільки для читання, збереження і показу картинок.

## Вибірка

105 кольорових супутникових знімків 256 x 256 з відкритого датасету UC Merced Land Use, по 5 знімків з кожного з 21 класу (поля, ліси, річки, пляжі, забудова, траси тощо). Знімки лежать у папці `data/images`.

## Пайплайни

Пайплайн це ланцюжок з 3 кроків: картинка проходить перший метод, його результат йде у другий, потім у третій. Кожен крок береться з іншої категорії методів.

| Пайплайн | Крок 1 | Крок 2 | Крок 3 |
|---|---|---|---|
| vika1 | гамма-корекція | вирівнювання гістограми | сегментація Оцу |
| vika2 | масштабування (найближчий сусід) | фільтр Кувахари | RGB в HSV і зміна насиченості |
| dasha1 | баланс білого «сірий світ» | білатеральний фільтр | регіональне зростання |
| dasha2 | RGB в YCbCr | лінійне розтягування контрасту | LBP |
| karolina1 | поворот на кут | сегментація k-means | статистика кожної області |
| karolina2 | логарифмічне перетворення | морфологічний градієнт | перетворення Хафа |

## Встановлення

Потрібен Python 3.10 або новіший. Встановити бібліотеки:

```bash
pip install -r requirements.txt
```

## Запуск

Команди запускаються з головної папки проєкту.

Подивитись, які пайплайни вже є:

```bash
python main.py --list
```

Обробити всі знімки пайплайном, наприклад `vika1`:

```bash
python main.py --pipeline vika1
```

Якщо треба інший файл з параметрами:

```bash
python main.py --pipeline vika1 --config my_config.json
```

```
results/

      1_gamma.png       після 1 кроку
      2_equalize.png    після 2 кроку

```

Так видно, що зробив кожен метод. Папка `results` у Git не потрапляє, її щоразу створює програма.

Битий або пошкоджений файл програма пропускає і пише про це в консоль, а не зупиняється.

## Параметри

Усі параметри лежать у `config.json`, код для цього змінювати не треба:

```json
{
  "seed": 0,
  "images_dir": "data/images",
  "results_dir": "results",
  "pipelines": {
    "vika1": {"gamma": 0.6}
  }
}
```

- `seed`: число для випадковості, щоб результат щоразу був однаковий
- `images_dir`: папка зі знімками
- `results_dir`: куди зберігати результати
- `pipelines`: параметри методів для кожного пайплайну

## Як додати свій пайплайн

1. У своєму файлі (`src/vika.py`, `src/dasha.py` або `src/karolina.py`) пишеш функції-кроки. Кожна отримує картинку і `params` з конфігу та повертає нову картинку:

```python
import numpy as np

def brighten(image, params):
    """робить картинку світлішою на params["value"]."""
    return image.astype(np.float64) + params["value"] # float, щоб не було переповнення
```

2. Додаєш пайплайн у `PIPELINES` свого файлу. Назву починай зі свого імені, щоб не збігтися з іншими:

```python
PIPELINES = {
    "vika1": [("gamma", gamma_correction), ("equalize", equalize), ("otsu", otsu)],
}
```

3. Параметри дописуєш у `config.json` в розділ `pipelines`.

4. Запускаєш `python main.py --pipeline vika1`.

Картинку на вході функція отримує завжди однакову: масив висота x ширина x 3 (R, G, B), числа від 0 до 255. Якщо на виході числа вийшли за 0..255, при збереженні вони обріжуться самі.
